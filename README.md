# Gestión y rentabilidad de clínica dental

Aplicación web para gestionar y analizar los servicios de una clínica dental en Perú: catálogo, fichas técnicas,
costos directos e indirectos, atenciones, dashboard y reportes en Excel.

> Documentación completa al finalizar la fase 7.

## Inicio rápido

```bash
npm install
cp .env.example .env
npx prisma migrate dev   # crea la base SQLite y carga los datos de ejemplo
npm run dev              # http://localhost:3000
```

Usuario de prueba: `admin@clinica.pe` / `admin123`
